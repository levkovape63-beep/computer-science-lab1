## Лабораторная работа 2

### Анализ веб-приложения и клиент-серверного взаимодействия

#### Цель работы

# Исследовать клиент-серверное взаимодействие веб-приложения с помощью инструментов разработчика браузера, проанализировать HTTP-запросы и ответы, передаваемые данные, cookies, а также взаимодействие Frontend, API и Backend.

#### Исследуемое веб-приложение

# **Ozon** — интернет-магазин для поиска и покупки товаров.

# **Пользовательский сценарий:** поиск товара, открытие его карточки и добавление товара в корзину.

#### Краткое описание результата

# В ходе лабораторной работы было исследовано клиент-серверное взаимодействие веб-приложения Ozon с использованием инструментов разработчика браузера Firefox. Изучены HTTP-запросы и ответы, их методы, заголовки, параметры и передаваемые данные.

# Проанализирован запрос добавления товара в корзину, выполняемый методом `POST` к API Ozon. Исследовано тело запроса, содержащее идентификатор товара и его количество, а также HTTP-ответ сервера со статусом `200 OK` и результатом успешного выполнения операции.

# Также были изучены cookies, используемые веб-приложением, и рассмотрено взаимодействие Frontend, API и Backend при выполнении пользовательского действия.

# На основе результатов исследования была уточнена архитектурная схема веб-приложения и построена отдельная схема выполнения пользовательского сценария добавления товара в корзину.
